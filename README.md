# A mathematical model of the vowel space — code repository

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23241627.svg)](https://doi.org/10.5281/zenodo.23241627)

This repository contains the complete, self-contained **Python** code needed
to reproduce the simulations, figures, tables and multimedia files of:

> **Frédéric Berthommier**, *A mathematical model of the vowel space*
> (Univ. Grenoble Alpes, CNRS, Grenoble INP, GIPSA-lab).
> **Research article (canonical): [arXiv:2111.00868v3](https://arxiv.org/abs/2111.00868v3)**
> (v2 is a dead version).

**New to the model?** Start with the didactic introduction
[`docs/tutorial.pdf`](docs/tutorial.pdf) (US English): theory, worked
examples, guided tour of the code, exercises.

An **open-access two-column edition of the article** (free template, no
proprietary JASA class) is provided in [`paper/`](paper/paper.pdf)
(LaTeX source + compiled PDF + Overleaf/arXiv-ready package
[`paper/arxiv_submission.zip`](paper/arxiv_submission.zip), `.bbl`
included) with a strict content verification script
([`scripts/verify_paper.py`](scripts/verify_paper.py)).

The paper establishes a bijection between the vowel space (F1, F2) and the
parameter space of vocal-tract models, using:

* the **three-phase mixing function** (Eq. 1-3): vocal-tract shapes
  generated from three seed vectors {i, j, k} along a θ cycle;
* the **generic model** (Eq. 4): 2 latent variables — the first two odd
  cosine Fourier coefficients (a1, a2) of the area function — plus the
  tract length L; 8 vowels [ɨ, u, o, ɔ, a, ɛ, e, i] with two formulas;
* the **coordination function** (Eq. 5-7):
  P(ρ, θ) = Ω + ρ Ψ₁ cos(Ψ₂ − θ), applied to two 4-tube models:
  the **DRM** (Distinctive Region Model, Table II) and **Fant's model**
  with 4 parameters {Xc, Ac, Al, L} (Table III);
* Monte-Carlo comparison of condition **C1** (4 uncorrelated parameters,
  uniform in Ω ± Ψ₁) vs **C2** (coordination function): the many-to-one
  articulatory-acoustic relation disappears in C2.

Formants are computed with the **transmission-line model (TLM)** of
P. Badin (ICP/GIPSA-lab, Grenoble) — electrical analog of the tube with
Fant (1960) losses and wall vibration, poles found by peak-picking +
secant refinement in the complex frequency plane.

## Scripts → paper content

| Script | Produces |
|---|---|
| `simu_gen.py` | generic-model cycle (Fig. 1 data, Mm. 1-2) |
| `simu_drm.py` | DRM cycle + SE / "est" estimates (Fig. 3 data, Mm. 3-4) |
| `simu_fant.py` | Fant cycle (Fig. 4b data, Mm. 5-6) |
| `monte_carlo.py drm\|fant` | C1 (1000 draws) + C2 (5000 draws) data of Figs. 3-7 |
| `fig1_generic.py` … `fig7_overlay.py` | Figures 1 to 7 in `figures/` |
| `make_multimedia.py` | Mm. 1-6 (8-vowel wav files + area-function movies) |
| `validate.py` | quantitative check against the MATLAB reference data |
| `verify_paper.py` | strict check of the open-access paper vs the original LaTeX |
| `convert_reference_data.py` | regenerates `data/reference/` from the original `.mat` |

## Quick start

```bash
pip install -r requirements.txt        # numpy, scipy, matplotlib

# 1. validate the Python TLM against the MATLAB reference (≈ 1 min)
python scripts/validate.py

# 2. compute the three model cycles (≈ 1 min)
python scripts/simu_gen.py
python scripts/simu_drm.py
python scripts/simu_fant.py

# 3. Monte-Carlo C1/C2 for the two 4-tube models (≈ 20 min)
python scripts/monte_carlo.py drm
python scripts/monte_carlo.py fant

# 4. regenerate the figures
python scripts/fig1_generic.py
python scripts/fig2_coordination.py
python scripts/fig3_drm.py
python scripts/fig4_fant.py
python scripts/fig5_dfi.py
python scripts/fig6_df_fit.py
python scripts/fig7_overlay.py

# 5. multimedia (Mm. 1-6): 8-vowel sounds + movies (≈ 15 min)
python scripts/make_multimedia.py
```

Every script accepts `--quick` for a fast preview, and the figure scripts
accept `--reference` to plot the original MATLAB Monte-Carlo draws instead
of the Python ones.

## Validation summary (Python vs compiled MATLAB)

| Quantity | Generic (lossless) | DRM (lossless) | Fant (lossy) |
|---|---|---|---|
| neutral F1, F2 | ≤ 0.1 Hz | ≤ 0.1 Hz | F2 ≤ 0.1 Hz; F1 ≈ 1.5-2 Hz* |
| cycle F1, F2 (122 / 62 phases) | ≤ 0.5 Hz | ≤ 0.8 Hz | F2 ≤ 0.5 Hz; F1 ≤ 2.2 Hz* |
| Fourier coefficients (a1, a2) | — | machine precision | machine precision |
| coordination transform (Table I) | exact | exact | exact |
| LPC lattice vs direct form | 2·10⁻¹⁵ | | |

\* the wall-vibration (lossy) setting shows a small systematic offset on
the most damped pole between the current MATLAB sources and the 2021
compiled binary that produced the reference `.mat`; F2 and all
coefficients agree to numerical precision. Invisible at figure scale.
Full report: [`figures/validation_report.txt`](figures/validation_report.txt).

## Notes on fidelity

* `vsmodel/tlm.py` is a faithful translation of the compiled MATLAB chain
  `TLMx.m / TLM3specx.m` + `vtn2frm_ftr_oral.m / nraph_oral.m /
  aire2spectre*.m / spectrelec.m / peakpick.m` (P. Badin, ICP). The
  `no_vibration` flag (1 = lossless walls for the generic model and the
  DRM, 0 = wall vibration for Fant's model) is propagated everywhere.
* `vsmodel/synthesis.py` translates the `voysynthx` chain (L. Girin):
  `Hfreq2lpc` (Levinson on the ifft of the power spectrum),
  `gen_src_3` (Rosenberg glottal pulses), `f_lpc_exc2sig` (PARCOR lattice
  with 1 ms inter-frame transitions). As in the 2021 supplement, the
  excitation is the fixed 0.5 s glottal source `excit.mat` shipped in
  `data/reference/excit.npy`.
* Figure 7 optionally overlays the 7-parameter Monte-Carlo cloud of
  Boë et al. (2019, *Science Advances* 5(12):eaaw3916, Fig. 4, L = 17.5 cm).
  That dataset is not redistributable: digitize their open-access figure
  into `data/boe2019_fig4.csv` (columns `f1,f2`) to reproduce the exact
  overlay; otherwise the DRM C2 domain and the human vowel-space
  ellipses (Peterson & Barney 1952) are drawn.
* Monte-Carlo draws use `numpy.random.RandomState(0)`: individual points
  differ from the MATLAB `rand` draws of the paper but the distributions
  are identical; the original draws are kept in `data/reference/` and can
  be plotted with `--reference`.
